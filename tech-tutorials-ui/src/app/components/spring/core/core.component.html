Spring Core - Complete Overview

1. What is Spring Core?

Spring Core is the fundamental part of the Spring Framework. It provides the foundation for building Java applications using Dependency Injection and Inversion of Control.

2. Core Concepts

  • IoC (Inversion of Control): Objects do not create their dependencies but get them from the Spring container.
  • DI (Dependency Injection): Injects dependencies into a class through constructor, setter, or field.
  • Bean: Object managed by the Spring IoC container.
  • ApplicationContext: Advanced factory interface for accessing beans.

3. Dependency Injection Types

  • Constructor Injection
  • Setter Injection
  • Field Injection (using annotations)
// Constructor Injection
    @Component
    public class Car {
    private Engine engine;
    @Autowired
    public Car(Engine engine) {
    this.engine = engine;
  }
}

4. Bean Configuration

  • XML-based configuration
  • Annotation-based configuration
  • Java-based configuration
// Java-based Configuration
    @Configuration
    public class AppConfig {
    @Bean
    public Engine engine() {
    return new Engine();
  }
}

5. Bean Lifecycle

  • Instantiation
  • Populate properties
  • Set Bean Name and Factory
  • Post-construct methods
  • Custom init-method
  • Bean ready for use
  • Custom destroy-method (if any)
@Component
    public class SampleBean implements InitializingBean, DisposableBean {
    public void afterPropertiesSet() {
    // initialization code
  }

  public void destroy() {
    // cleanup code
  }
}

6. Annotations

  • @Component, @Service, @Repository, @Controller
  • @Autowired – automatic injection
  • @Qualifier – specify which bean to inject
  • @Value – inject values from properties
  • @PostConstruct, @PreDestroy – lifecycle hooks

7. Spring Modules Around Core

  • Spring AOP
  • Spring ORM
  • Spring JDBC
  • Spring MVC
  • Spring Security

8. Example: Minimal Spring Core App

// AppConfig.java
    @Configuration
    @ComponentScan("com.example")
    public class AppConfig {}

// Main.java
public class Main {
    public static void main(String[] args) {
    ApplicationContext context = new AnnotationConfigApplicationContext(AppConfig.class);
    Car car = context.getBean(Car.class);
    car.drive();
  }
}

9. Benefits of Spring Core

  • Loose coupling
  • Easy testability
  • Reusable code
  • Flexible configuration
