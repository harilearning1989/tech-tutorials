🔧 Angular 19 Services Tutorial (Using Standalone APIs)

Angular 19 fully embraces standalone components. This means we no longer need to define NgModules. In this tutorial, we will explore what Angular services are, how to create and use them, and how they work in a module-less Angular 19 app.

📘 What is a Service in Angular?

A service is a class in Angular that provides logic or data that can be shared across components. Services are used to:

  • Share data between components
  • Handle business logic
  • Make HTTP requests
  • Access browser APIs

Services are typically decorated with @Injectable(), and registered with Angular’s dependency injection system.

🛠️ Step 1: Creating the Service

File: src/app/services/data.service.ts

// Import the Injectable decorator 
import { Injectable } from '@angular/core';
// The service is provided at the root level (app-wide singleton) 

      @Injectable({
        providedIn: 'root'
      })
      export class DataService {
      private data: string[] = [];

      constructor() {}

      addItem(item: string) {
        this.data.push(item);
      }

      getItems(): string[] {
        return this.data;
      }
    }

This service defines a private array and methods to add and retrieve data. It's registered globally using providedIn: 'root', so it's automatically available everywhere in the app.

🧩 Step 2: Using the Service in a Standalone Component

File: src/app/components/data-view.component.ts

  
    import { Component } from '@angular/core';
    import { CommonModule } from '@angular/common';
    import { FormsModule } from '@angular/forms';
    import { DataService } from '../services/data.service';

    @Component({
    selector: 'app-data-view',
    standalone: true,
    imports: [CommonModule, FormsModule],
    template: `
    <h2>Service Example</h2>
    <input [(ngModel)]="item" placeholder="Enter item" />
    <button (click)="addItem()">Add</button>

    <ul>
    <li *ngFor="let i of items">
{{ i }}
</li>
    </ul>
    `
    })
    export class DataViewComponent {
    item = '';
    items: string[] = [];

    constructor(private dataService: DataService) {}

    addItem() {
      this.dataService.addItem(this.item);
      this.item = '';
      this.items = this.dataService.getItems();
    }

    ngOnInit() {
      this.items = this.dataService.getItems();
    }
    }

In this component, we inject the DataService via the constructor. We bind an input field to item and call addItem() on button click. The list displays all added items.

🎯 Step 3: App Component (Bootstrapping)

File: src/app/app.component.ts

      
        import { Component } from '@angular/core';
        import { DataViewComponent } from './components/data-view.component';

        @Component({
        selector: 'app-root',
        standalone: true,
        imports: [DataViewComponent],
        template: `<app-data-view />`
        })
        export class AppComponent {}

This is the root component. It's also a standalone component, and it simply displays the <app-data-view> component.

🚀 Step 4: Main Entry File

File: src/main.ts

      
      import { bootstrapApplication } from '@angular/platform-browser';
      import { AppComponent } from './app/app.component';

      bootstrapApplication(AppComponent)
      .catch(err => console.error(err));

Angular 19 apps use bootstrapApplication() instead of modules to start the app.

📁 Suggested Project Structure

src/
├── app/
│ ├── services/
│ │ └── data.service.ts
│ ├── components/
│ │ └── data-view.component.ts
│ └── app.component.ts
└── main.ts

🧠 Key Angular 19 Concepts

  • Standalone Component: Declared with standalone: true, no NgModule needed.
  • Service Injection: Works the same, but no module registration is required when providedIn: 'root'.
  • Bootstrap: Uses bootstrapApplication() instead of AppModule.
  • Component Imports: Each component explicitly imports its dependencies like FormsModule, CommonModule, etc.

▶️ Running the App

Use Angular CLI to run the app:

npm install -g @angular/cli
ng new angular-19-service-demo --standalone
cd angular-19-service-demo
# Replace the contents with the files shown above
ng serve

✅ Summary

Angular 19 simplifies application structure using standalone components. Services work the same as before, but now you don’t need NgModules to use them. This tutorial showed how to:

  • Create a reusable service
  • Inject the service in a standalone component
  • Bootstrap the application without modules

You're now ready to use Angular 19 services in real-world apps!
