🎯 Angular Linting & Formatting Guide

Linting and formatting help maintain consistent code style, detect errors early, and improve developer collaboration. Angular supports ESLint, Prettier, and other tools.

🔍 What is Linting?

Linting analyzes your code for potential issues:

  • Code style violations
  • Potential bugs
  • Deprecated syntax

🎨 What is Formatting?

Formatting ensures consistent spacing, indentation, and alignment across your codebase.

🛠️ Step 1: Setup ESLint in Angular

Install ESLint:

ng add @angular-eslint/schematics

This will:

  • Remove TSLint if present
  • Install ESLint dependencies
  • Generate .eslintrc.json

📄 .eslintrc.json

{ "root": true, "overrides": [ { "files": ["*.ts"], "extends": ["plugin:@angular-eslint/recommended"], "rules": { "@typescript-eslint/no-unused-vars": "warn" } }, { "files": ["*.html"], "extends": ["plugin:@angular-eslint/template/recommended"], "rules": {} } ] }

Configure rules as per your team’s style guide.

🎯 Step 2: Add Prettier (Optional but Recommended)

npm install --save-dev prettier eslint-config-prettier

📄 .prettierrc

{ "singleQuote": true, "semi": true, "trailingComma": "all", "printWidth": 100 }

📄 .eslintignore

dist/ node_modules/ coverage/

📄 .prettierignore

dist/ node_modules/ coverage/

📦 Step 3: Add NPM Scripts

In package.json:

"scripts": { "lint": "ng lint", "format": "prettier --write \"src/**/*.{ts,html,scss}\"", "lint:fix": "ng lint --fix" }

✅ Commands Summary

Command Description
ng lint Lint TypeScript and HTML files
ng lint --fix Auto-fix lint issues
npm run format Apply Prettier formatting

💡 Best Practices

  • Use Prettier for formatting, ESLint for rules
  • Run lint and format before commits
  • Use Husky + Lint-Staged for pre-commit hooks
  • Share configs across teams via an internal npm package

🔐 Husky + Lint-Staged (Optional)

npm install --save-dev husky lint-staged npx husky install

In package.json

"lint-staged": { "src/**/*.{ts,html,scss}": [ "prettier --write", "ng lint --fix" ] }

📚 Summary

  • ESLint replaces deprecated TSLint
  • Prettier formats code consistently
  • Use ng lint and prettier --write for code quality
  • Automate with scripts and Git hooks
⚠️ Angular 12+ defaults to ESLint for new projects using the community @angular-eslint schematics.
