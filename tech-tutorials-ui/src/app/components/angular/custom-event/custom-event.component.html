🔁 Angular 19 Custom Event Tutorial (Standalone)

In Angular, components can communicate with each other. A common pattern is for a child component to emit a custom event that the parent component listens to.

In Angular 19 standalone apps, the pattern remains the same using the @Output() decorator and EventEmitter.

📘 Step 1: Create the Child Component (Emits Custom Event)

File: src/app/components/child.component.ts

      
    import { Component, Output, EventEmitter } from '@angular/core';
    import { CommonModule } from '@angular/common';

    @Component({
      selector: 'app-child',
      standalone: true,
      imports: [CommonModule],
      template: `
      <h3>Child Component</h3>
      <button (click)="sendMessage()">Send Message to Parent</button>
      `
      })
    export class ChildComponent {
    @Output() message = new EventEmitter<string>();

      sendMessage() {
        this.message.emit("Hello from the Child!");
      }
    }
  • @Output() creates a custom event.
  • message is the name of the event.
  • When the button is clicked, the event is emitted with a message.

🧩 Step 2: Create the Parent Component (Handles Custom Event)

File: src/app/components/parent.component.ts

      
          import { Component } from '@angular/core';
          import { CommonModule } from '@angular/common';
          import { ChildComponent } from './child.component';

          @Component({
            selector: 'app-parent',
            standalone: true,
            imports: [CommonModule, ChildComponent],
            template: `
            <h2>Parent Component</h2>
            <p>Message from child: 

            {{ childMessage }}

            </p>

            <app-child (message)="receiveMessage($event)"></app-child>
            `
            })
          export class ParentComponent {
          childMessage = '';

            receiveMessage(message: string) {
              this.childMessage = message;
            }
          }
  • (message)="receiveMessage($event)" listens for the child’s event.
  • The $event contains the data emitted by the child.

🎯 Step 3: App Component (Bootstrap Entry)

File: src/app/app.component.ts

      
    import { Component } from '@angular/core';
    import { ParentComponent } from './components/parent.component';

    @Component({
      selector: 'app-root',
      standalone: true,
      imports: [ParentComponent],
      template: `<app-parent></app-parent>`
      })
    export class AppComponent {}

🚀 Step 4: Main Entry Point

File: src/main.ts

      
    import { bootstrapApplication } from '@angular/platform-browser';
    import { AppComponent } from './app/app.component';

    bootstrapApplication(AppComponent)
    .catch(err => console.error(err));

🧠 Key Angular 19 Concepts Used

  • Standalone Components: All components use standalone: true.
  • @Output & EventEmitter: For emitting custom events from child to parent.
  • $event: The special template variable containing the emitted data.
  • Bootstrap without NgModules: Using bootstrapApplication.

You now understand how to use custom events in Angular 19 with standalone components:

  2. Emit data with EventEmitter
