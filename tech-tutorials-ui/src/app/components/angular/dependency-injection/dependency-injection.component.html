Angular Dependency Injection Tutorial

What is Dependency Injection?

Dependency Injection (DI) is a design pattern where a class receives its dependencies from an external source rather than creating them itself. Angular has a built-in dependency injection framework that makes it easy to manage services and components.

Creating a Service

Let's create a simple logging service:

// src/app/logger.service.ts
import { Injectable } from '@angular/core';

      @Injectable({
        providedIn: 'root' // This makes the service available app-wide
})
      export class LoggerService {
      log(msg: string) {
    console.log('LoggerService: ' + msg);
  }
}

Injecting the Service into a Component

Now inject the LoggerService into a component:

// src/app/app.component.ts
import { Component } from '@angular/core';
import { LoggerService } from './logger.service';

      @Component({
        selector: 'app-root',
        template: `
        <h1>Dependency Injection Demo</h1>
        <button (click)="doLog()">Log Message</button>
        `
        })
      export class AppComponent {
      constructor(private logger: LoggerService) {}

  doLog() {
    this.logger.log('Button clicked!');
  }
}

Providing Services in Modules

You can also provide a service in a specific module instead of root:

// src/app/feature/feature.module.ts
import { NgModule } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FeatureComponent } from './feature.component';
import { LoggerService } from '../logger.service';

      @NgModule({
        declarations: [FeatureComponent],
        imports: [CommonModule],
        providers: [LoggerService] // Provided only in this module
})
      export class FeatureModule {}

Hierarchical Injectors

Angular uses hierarchical injectors, meaning each component can have its own injector. If a service is provided at the component level, it creates a new instance for that component. 

@Component({
      selector: 'child-component',
      template: '<p>Child</p>',
      providers: [LoggerService] // Unique instance for this component
})
      export class ChildComponent {
      constructor(private logger: LoggerService) {
    this.logger.log('Child component logger');
  }
}

Conclusion

  • Use @Injectable({ providedIn: 'root' }) for singleton services.
  • Inject services using constructor injection.
  • Override service scope by using providers at component or module level.

Angular DI helps keep your code clean, testable, and scalable.
