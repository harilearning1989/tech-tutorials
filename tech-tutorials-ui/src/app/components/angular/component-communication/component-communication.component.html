Angular Component Communication

This tutorial explains the key patterns used in Angular to communicate between components.

1. Parent to Child: @Input()

Use @Input to pass data from a parent component to its child.

Parent Template

<app-child [message]="parentMessage"></app-child>

Parent Component

export class ParentComponent {
      parentMessage = 'Hello from Parent';
}

Child Component

import { Component, Input } from '@angular/core';

      @Component({
        selector: 'app-child',
        template: '
Child says: {{ message }}
'
        })
      export class ChildComponent {
      @Input() message!: string;
}

2. Child to Parent: @Output() + EventEmitter

Use @Output to emit an event from the child that the parent can listen to.

Parent Template

<app-child (notify)="onNotify($event)"></app-child>

Parent Component

onNotify(message: string) {
      alert('Received from child: ' + message);
}

Child Component

import { Component, Output, EventEmitter } from '@angular/core';

      @Component({
        selector: 'app-child',
        template: '<button (click)="sendMessage()">Send Message</button>'
        })
      export class ChildComponent {
      @Output() notify = new EventEmitter<string>();

  sendMessage() {
    this.notify.emit('Hello from Child!');
  }
}

3. Sibling to Sibling: Shared Service

Use a service with RxJS Subject to communicate between unrelated components.

Shared Service

import { Injectable } from '@angular/core';
import { Subject } from 'rxjs';

      @Injectable({ providedIn: 'root' })
      export class MessageService {
      private messageSource = new Subject<string>();
  message$ = this.messageSource.asObservable();

  sendMessage(msg: string) {
    this.messageSource.next(msg);
  }
}

Sender Component

constructor(private messageService: MessageService) {}

send() {
      this.messageService.sendMessage('Hello from Sender');
}

Receiver Component

constructor(private messageService: MessageService) {}

ngOnInit() {
      this.messageService.message$.subscribe(msg => {
    console.log('Received:', msg);
  });
}

4. Access Child via @ViewChild()

Use @ViewChild to access a child component's methods or properties.

Child Component

@Component({ selector: 'app-child', template: '' })
      export class ChildComponent {
      sayHi() {
    console.log('Hello from Child Component!');
  }
}

Parent Component

import { ViewChild } from '@angular/core';

export class ParentComponent {
      @ViewChild(ChildComponent) child!: ChildComponent;

      callChild() {
    this.child.sayHi();
  }
}

5. Using Template Reference Variables

You can also access child elements using a reference variable in the template.

<input #userInput type="text" />
<button (click)="log(userInput.value)">Log Input</button>
log(value: string) {
      console.log(value);
}

Best Practices

  • Use @Input/@Output for simple parent-child communication.
  • Use a shared service for complex or cross-component communication.
  • Minimize direct DOM access with @ViewChild.
  • Always unsubscribe from Observables when using services.
