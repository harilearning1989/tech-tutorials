🌐 Angular 19 + REST API Integration (Standalone Components)

In this tutorial, we demonstrate how to call a REST API using Angular 19. The example uses a public JSON API (e.g., https://jsonplaceholder.typicode.com/users) to fetch user data and display it in a component.

📦 Step 1: Install Angular and Create a Standalone App

npm install -g @angular/cli
ng new angular19-api-demo --standalone
cd angular19-api-demo

Then replace the boilerplate with the following files below.

🔧 Step 2: Setup the Service to Call REST API

File: src/app/services/user.service.ts

      
    import { Injectable } from '@angular/core';
    import { HttpClient } from '@angular/common/http';
    import { Observable } from 'rxjs';

    export interface User {
      id: number;
      name: string;
      email: string;
    }

    @Injectable({ providedIn: 'root' })
    export class UserService {
      private apiUrl = 'https://jsonplaceholder.typicode.com/users';

      constructor(private http: HttpClient) {}

      getUsers(): Observable<User[]> {
        return this.http.get<User[]>(this.apiUrl);
      }
    }
  • This service uses HttpClient to call a public API.
  • Observable<User[]> lets components subscribe to the data.

🧩 Step 3: Display API Data in a Standalone Component

File: src/app/components/user-list.component.ts

      
    import { Component, OnInit } from '@angular/core';
    import { CommonModule } from '@angular/common';
    import { HttpClientModule } from '@angular/common/http';
    import { UserService, User } from '../services/user.service';

    @Component({
      selector: 'app-user-list',
      standalone: true,
      imports: [CommonModule, HttpClientModule],
      template: `
      <h2>User List</h2>

      <div *ngIf="loading">Loading...</div>
    <div *ngIf="error">Error: 
{{ error }}
</div>

      <ul>
      <li *ngFor="let user of users">
    <strong>
{{ user.name }}
</strong> - 
{{ user.email }}

      </li>
      </ul>
      `
      })
    export class UserListComponent implements OnInit {
        users: User[] = [];
        loading = true;
        error = '';

        constructor(private userService: UserService) {}

        ngOnInit() {
          this.userService.getUsers().subscribe({
          next: data => {
          this.users = data;
          this.loading = false;
        },
        error: err => {
          this.error = 'Failed to load users';
          this.loading = false;
        }
      });
      }
    }
  • Uses *ngIf to show loading and error states.
  • Subscribes to the service and updates the view with the results.

🏁 Step 4: Create App Component

File: src/app/app.component.ts

      
    import { Component } from '@angular/core';
    import { UserListComponent } from './components/user-list.component';

    @Component({
    selector: 'app-root',
    standalone: true,
    imports: [UserListComponent],
    template: `<app-user-list></app-user-list>`
    })
    export class AppComponent {}

🚀 Step 5: Bootstrap the App

File: src/main.ts

      
    import { bootstrapApplication } from '@angular/platform-browser';
    import { AppComponent } from './app/app.component';

    bootstrapApplication(AppComponent)
    .catch(err => console.error(err));

🧠 Key Concepts in Angular 19 API Integration

  • Standalone Components: No need for NgModules.
  • HttpClient: Core service for making HTTP requests.
  • Observable Pattern: Asynchronous, reactive data handling.
  • Error Handling: Using subscribe() error callbacks.

✅ Summary

With Angular 19 and standalone components, calling a REST API is straightforward:

  1. Create a service with HttpClient.
  2. Inject the service into a component.
  3. Use subscribe() to process API results.
  4. Handle loading and error states in the view.

You're now ready to connect Angular 19 to any REST API! 🎉
