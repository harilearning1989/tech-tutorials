🗃️ Browser Storage Mechanisms – Full Tutorial

Web browsers provide several ways to store data on the client side. These include:

  • localStorage
  • sessionStorage
  • Cookies
  • IndexedDB

📦 1. localStorage

Stores data with no expiration time. Available even after browser restarts.

// Set item localStorage.setItem("username", "John"); // Get item let user = localStorage.getItem("username"); // Remove item localStorage.removeItem("username"); // Clear all localStorage.clear();

Storage Limit: ~5MB

📦 2. sessionStorage

Same API as localStorage, but data is cleared when tab/window is closed.

sessionStorage.setItem("session", "active"); let state = sessionStorage.getItem("session");

Use Case: Temp data, page navigation states

🍪 3. Cookies

Used for small data, especially server-side readable data (like auth tokens).

// Set cookie document.cookie = "user=Jane; expires=Fri, 31 Dec 2025 12:00:00 UTC; path=/"; // Read cookie console.log(document.cookie); // Delete cookie (set past expiry) document.cookie = "user=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/";

Size Limit: ~4KB per cookie

Security: Can use Secure and HttpOnly flags (from server)

🗄️ 4. IndexedDB

A low-level API for storing large structured data (objects, files). Async and powerful.

// Open DB let request = indexedDB.open("MyDatabase", 1); // Create store request.onupgradeneeded = function(event) { let db = event.target.result; db.createObjectStore("users", { keyPath: "id" }); }; // Add data request.onsuccess = function(event) { let db = event.target.result; let tx = db.transaction("users", "readwrite"); let store = tx.objectStore("users"); store.add({ id: 1, name: "Alice" }); };

Use Case: Offline apps, large object storage

🔐 Security Tips

  • Never store sensitive data (passwords, tokens) in localStorage
  • Use HttpOnly & Secure flags for cookies
  • Use HTTPS to protect all data storage operations
  • Use encryption before storing critical data
⚠️ localStorage and sessionStorage are accessible via JavaScript and vulnerable to XSS. Avoid using them for authentication tokens without protection.

📚 Summary

  • localStorage – Persistent key/value storage
  • sessionStorage – Temporary tab storage
  • Cookies – Server-readable data, limited size
  • IndexedDB – Complex, structured large storage

Each has its ideal use case depending on your app’s needs!
