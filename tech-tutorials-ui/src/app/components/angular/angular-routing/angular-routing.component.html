Angular Routing Tutorial

This tutorial explains how to set up routing in Angular to navigate between different components (pages) in your application.

Step 1: Create an Angular Project

Use Angular CLI to create a new project with routing support:

ng new my-routing-app

Make sure to choose Yes when asked to add routing, and select your preferred stylesheet format.

Step 2: Create Components

Create separate components for each route/page:


ng g c home
ng g c about
ng g c contact

Step 3: Configure Routing

Open src/app/app-routing.module.ts and define your routes like this:


import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { HomeComponent } from './home/home.component';
import { AboutComponent } from './about/about.component';
import { ContactComponent } from './contact/contact.component';

const routes: Routes = [
    { path: '', component: HomeComponent },
    { path: 'about', component: AboutComponent },
    { path: 'contact', component: ContactComponent },
    { path: '**', redirectTo: '' } // Wildcard route for a 404 page
];

    @NgModule({
      imports: [RouterModule.forRoot(routes)],
      exports: [RouterModule]
      })
    export class AppRoutingModule { }

Step 4: Add Router Outlet

In app.component.html, add a navigation menu and a router outlet:


<nav>
  <a routerLink="/">Home</a>
  <a routerLink="/about">About</a>
  <a routerLink="/contact">Contact</a>
</nav>

<hr />

<router-outlet></router-outlet>

Step 5: Add Content to Components

Each component (like home.component.html) can have its own content:


<h2>Welcome to the Home Page</h2>
<p>This is the homepage of our Angular routing example.</p>

Step 6: Run the Application

Run the app and navigate between pages:

ng serve

Visit http://localhost:4200 in your browser. Clicking the nav links will change the page content without reloading.

Bonus: Wildcard Route (Page Not Found)

Add a wildcard route to handle invalid URLs:


{ path: '**', redirectTo: '' }

Conclusion

You've now implemented basic Angular routing with multiple components. This helps create multi-page applications using a single-page app structure.
