Angular 19 Data Binding Tutorial

1. Interpolation

Displays data from the component to the template using double curly braces.

{{ title }}

2. Property Binding

Binds DOM properties to component class properties using square brackets.

<img [src]="imageUrl" alt="Image">

3. Attribute Binding

Used when binding standard HTML attributes like aria-label.

<button [attr.aria-label]="label">Click Me</button>

4. Class Binding

Dynamically adds or removes CSS classes based on component conditions.

<div [class.active]="isActive">Active Box</div>

5. Style Binding

Binds inline CSS styles dynamically.

<div [style.background-color]="bgColor">Styled Box</div>

6. Event Binding

Binds an event (e.g., click) to a method in the component class.

<button (click)="onClick()">Click Me</button>

7. Two-Way Binding

Binds data in both directions using [(ngModel)]. Requires FormsModule.

<input [(ngModel)]="username">
<p>Hello, 
{{ username }}
!</p>

8. Signal Binding (Angular 16+)

Angular Signals provide reactive state management.

<p>Counter: 
{{ counter() }}
</p>
<button (click)="counter.update(c => c + 1)">+</button>
