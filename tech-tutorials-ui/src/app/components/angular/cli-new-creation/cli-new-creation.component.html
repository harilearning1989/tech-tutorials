Command Line Interface

The Angular CLI (Command Line Interface) is a powerful tool for creating, managing, building, and testing Angular applications from the command line.

Key Features

1. Scaffolding

Generate app skeletons and Angular constructs like components and services:

ng new my-app
ng g c my-component

2. Development Server

Run a local server with live reload:

ng serve

Run a local server with live reload and open in browser automatically

ng serve -o

Run a local server with custom port and open in browser automatically

ng serve -p 4300 -o

here -p is port and -o is open

3. Build Tools

Build your application for different environments:

ng build --prod

4. Testing

Run unit and end-to-end tests:

ng test
ng e2e

5. Linting & Formatting

Check code style and syntax issues:

ng lint

6. Configuration Management

Supports multiple environments like dev, staging, and production with configurable settings.

Installation

npm install -g @angular/cli

Check Angular CLI Version

ng version

Angular CLI helps automate repetitive tasks, enforce best practices, and streamline the development process.
