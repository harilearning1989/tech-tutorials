Angular Templates Tutorial

What is a Template in Angular?

An Angular template is HTML combined with Angular directives and binding markup that tells Angular how to render the component.

Templates are part of Angular components and define the user interface.

Basic Component Template Example

// app.component.ts
      @Component({
  selector: 'app-root',
  template: \`
      <h1>
{{ title }}
</h1>
    <p>Welcome to Angular Templates!</p>
        \`
          })
export class AppComponent {
      title = 'My Angular App';
}

Or use an external HTML file:

// app.component.ts
      @Component({
        selector: 'app-root',
        templateUrl: './app.component.html'
        })
      export class AppComponent {
      title = 'My Angular App';
}

Template Syntax Features

  • Interpolation:

    {{ value }}

  • Property Binding: [property]="value"
  • Event Binding: (event)="handler()"
  • Two-way Binding: [(ngModel)]="value"
  • Structural Directives: *ngIf, *ngFor

Example: Template with Bindings

<input [(ngModel)]="username" placeholder="Enter name" />

      
Hello, {{ username }}


<button (click)="reset()">Reset</button>
// app.component.ts
export class AppComponent {
      username = '';

      reset() {
    this.username = '';
  }
}

Using Template Reference Variables

<input #nameInput />
<button (click)="greet(nameInput.value)">Greet</button>
// app.component.ts
greet(name: string) {
      alert('Hello, ' + name + '!');
}

ng-template and ng-container

<ng-template> is used to define reusable or conditionally rendered templates.

<ng-template #loading>
  <p>Loading data...</p>
</ng-template>

<div *ngIf="isLoading; else dataLoaded">
  <ng-container [ngTemplateOutlet]="loading"></ng-container>
</div>

<ng-template #dataLoaded>
  <p>Data has been loaded!</p>
</ng-template>

Best Practices

  • Keep templates clean and logic-free (move logic to the component).
  • Use external HTML files for large templates.
  • Use ng-container to group elements without creating extra DOM nodes.
  • Leverage *ngIf, *ngFor wisely to control rendering.
