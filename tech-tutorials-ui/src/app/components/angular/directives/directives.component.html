Angular Directives Tutorial

What are Directives?

In Angular, directives are classes that add behavior to elements in your Angular applications.

There are 3 types of directives:

  • Component Directives – Directives with a template (these are components)
  • Structural Directives – Change the DOM layout (e.g. *ngIf, *ngFor)
  • Attribute Directives – Change the appearance or behavior of an element (e.g. ngClass, ngStyle)

Built-in Structural Directive Example

<ul>
      <li *ngFor="let item of items" >
{{ item }}
</li>
</ul>

<p *ngIf="isLoggedIn">Welcome back!</p>

Built-in Attribute Directive Example

<div [ngClass]="{ 'active': isActive }">Status</div>
<div [ngStyle]="{ 'color': isError ? 'red' : 'green' }">Message</div>

Creating a Custom Attribute Directive

ng g d highlight

Let's build a directive that changes the background color of an element on hover.

// src/app/highlight.directive.ts
import { Directive, ElementRef, HostListener, Input } from '@angular/core';

      @Directive({
        selector: '[appHighlight]'
        })
      export class HighlightDirective {
      @Input() highlightColor: string = 'yellow';

      constructor(private el: ElementRef) {}

  @HostListener('mouseenter') onMouseEnter() {
    this.highlight(this.highlightColor || 'lightgray');
  }

  @HostListener('mouseleave') onMouseLeave() {
    this.highlight('');
  }

  private highlight(color: string) {
    this.el.nativeElement.style.backgroundColor = color;
  }
}

Registering the Directive

// src/app/app.module.ts
import { NgModule } from '@angular/core';
import { BrowserModule } from '@angular/platform-browser';
import { AppComponent } from './app.component';
import { HighlightDirective } from './highlight.directive';

      @NgModule({
        declarations: [
        AppComponent,
        HighlightDirective
        ],
        imports: [ BrowserModule ],
        bootstrap: [ AppComponent ]
        })
      export class AppModule { }

Using the Custom Directive

<p appHighlight highlightColor="lightblue">
  Hover to highlight this paragraph!
</p>

<button appHighlight>Hover me!</button>

Creating a Custom Structural Directive

This example creates a directive that only shows an element when a condition is false (opposite of *ngIf).

// src/app/unless.directive.ts
import { Directive, Input, TemplateRef, ViewContainerRef } from '@angular/core';

      @Directive({
        selector: '[appUnless]'
        })
      export class UnlessDirective {
      constructor(private templateRef: TemplateRef<any>, private viewContainer: ViewContainerRef) {}

  @Input() set appUnless(condition: boolean) {
    if (!condition) {
      this.viewContainer.createEmbeddedView(this.templateRef);
    } else {
      this.viewContainer.clear();
    }
  }
}

Using the Custom Structural Directive

<p *appUnless="isLoggedIn">
  You must log in to continue.
</p>

Summary

  • Directives enhance HTML with custom behavior.
  • Structural directives modify the DOM layout.
  • Attribute directives change element appearance or behavior.
  • You can create custom directives using @Directive and Angular's DOM APIs.
