🗂️ Folder & File Descriptions

📁 node_modules/

Contains installed npm packages. Automatically generated after npm install.

📁 src/

Main source code for the app.

📁 app/

  • app.module.ts – Root module of the application
  • app-routing.module.ts – Routing configuration
  • app.component.ts – Main component logic
  • app.component.html – Main component template
  • app.component.css – Main component styling

📁 assets/

Static files like images, icons, fonts.

📁 environments/

  • environment.ts – Dev settings
  • environment.prod.ts – Production settings

📄 index.html

Main HTML file loaded by the browser.

📄 main.ts

Entry point for bootstrapping the Angular application.

📄 styles.css

Global CSS styles.

📄 polyfills.ts

Browser compatibility support.

📄 test.ts

Test configuration setup for Angular's testing utilities.

🔧 Configuration Files

📄 angular.json

Angular CLI settings including build and serve options.

📄 package.json

Project metadata, dependencies, and npm scripts.

"scripts": {
    "ng": "ng",
    "start": "ng serve",
    "build": "ng build",
    "test": "ng test"
}

📄 tsconfig.json

Base TypeScript configuration.

  • tsconfig.app.json – App-specific TS config
  • tsconfig.spec.json – Test-specific TS config

📄 karma.conf.js

Karma test runner config file.

📄 .editorconfig

Editor formatting rules for consistency across environments.

📄 .gitignore

Specifies files to exclude from version control (e.g., node_modules).

📄 README.md

Markdown file with project instructions and info.

🧩 Notes

  • If using standalone components, app.module.ts may be replaced with bootstrapApplication() in main.ts.
  • If using SCSS, styles files will be .scss instead of .css.
  • Environment switching is handled by the fileReplacements array in angular.json.
