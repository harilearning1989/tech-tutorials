How to Install Angular and Required Software

✅ Step 1: Install Node.js and npm

Angular requires Node.js and npm (Node Package Manager).

  • Go to: https://nodejs.org/
  • Download the LTS version and install it with default settings.

✅ Verify installation:

node -v
npm -v

🚀 Step 2: Install Angular CLI

The Angular CLI helps you create and manage Angular apps.

npm install -g @angular/cli

✅ Verify installation:

ng version

🏗️ Step 3: Create a New Angular Project

ng new my-angular-app

The CLI will ask a few setup questions. Choose your preferences and press Enter.

▶️ Step 4: Serve the Application Locally

cd my-angular-app
ng serve

Then open your browser and go to: http://localhost:4200

  • Visual Studio Code – Download here
